## 2026-11-20(Claude)

### 1. ヨットの CPU の書き直し(規則は変えない) — 未(Android・exe)
- Web 版: `web/pc-firebase/core/asobi-pc-core.mjs` の `var YACHT_AI = (function () {…})()` と `Yacht$Companion$brain$lambda`。
  Kotlin 側では `core/src/commonMain/kotlin/jp/yonekou/asobi26/core/games/Yacht.kt` の `val brain`(306 行目付近)と、補助の `value`・`bestCategory`・`expected`・`simpleHold` を置き換える。
  注意: このリポジトリの `Yacht.kt` の `simpleHold` は、Web 版の JS(前の版)より新しい形(残りの役を少し見る)になっていて、JS とは食い違っていた。今回 JS 側は上の書き直しで置き換えたので、Kotlin も同じ考え方に合わせる。
- 前の問題: 中級・初級は `simpleHold`(一番多い目を残す/4連続ならストレート用に残す)で、残りの役を見ていなかった。
  例: ヨットだけ残りで 3・4・5・6・6 → ストレート用に 3〜6 を残す。上級も1回先の期待値だけ。
- 新しい考え方:
  1. 役 c を今つけた時の値打ち `value(c, dice)`:
     - 点数 `sc` から始める。
     - 上段(1〜6)で、上段ボーナスがまだ取れていて、まだ届く見込みがある時: `+ (sc − 3×目) × 1.2`、この役で 63 に届くなら `+15`。
     - 後に残した時の見込み点を引く: `− LATER[c] × w`。`LATER = [2.1, 4.2, 6.3, 8.4, 10.5, 12.6, 22, 11, 10, 10, 12, 13]`(1〜6・チョイス・フォーダイス・フルハウス・Sストレート・Bストレート・ヨット)、`w = min(1, (残りの役の数 − 1) / 3)`。
     - 初級はこの補正をしない(`value = sc`)。
  2. 5 個の目の組(252 通り)ごとに、表 `E0 = max_c value(c, 組)`。
     `E_r(組) = max(E_{r−1}(組), max_{残す目} Σ 確率 × E_{r−1}(残す目+振った目))`(r 回振り直せる時)。
  3. 手番の判断: 振り直しが残っていれば、手の番号 0〜30(残す目のビット)ごとに `Σ 確率 × E_{d−1}(…)` を出し、今つけた時の値打ちより大きい物があれば最大の物、無ければ `100 + 一番値打ちの高い役`。
     読む深さ `d`: 上級 = 残りの振り直し回数、初級・中級 = 1。表は記入表が同じ間は使い回す。
  4. 振る前(rollsLeft = 3)は今までどおり 0。
- 強さ(1人で200回の平均): 初級 138→160・中級 147→182・上級 169→185 点。上級の1手は 50ms 程度(JS)。
- 確かめ方: ヨットだけ残りで 3・4・5・6・6 → 6・6 を残す/2・2・2・2・5 → 2 を4つ残す。

### 4. 坊主めくりの設定・演出 — 未(坊主めくりがある版)
- `web/pc-firebase/js/poet-cards.js`・`css/app.css`(`.poet-omen`・`.cutin.wa-cut`・`.f-fude`)・`js/rules.js`。
- 設定「姫ボーナス」(姫を引いた時に場札が無ければもう1枚。**既定あり**)。保存のキーは `himeBonus`(前の `hime` は既定が「なし」だったので引き継がない)。対局の状態では今までどおり `hime: 'on'|'off'`。
- 設定「めくれる札の坊主・姫」(**既定は数を見せる**): 札を引くたびにホストが各山の一番上の札の役を数え、`state.tops = {bozu, hime}` に入れる。山札の上に「めくれる札に 坊主 n枚・姫 n枚」と出す(どの山かは出さない)。状態の `peek: 'on'|'off'`。
- カットイン: 筆文字(Yuji Boku)。姫 = 桜色、坊主 = 墨色、蝉丸(全員の札を場へ)= 古代紫で「蝉丸」＋小さく「全員の札を場へ」。姫ボーナスで続けて引く時は「姫ボーナス」＋「もう1枚」。
- 手札が 0 枚の時は札を出さない(坊主の札は着地した後に消す)。引いた時は、前の札を着地まで残す(手札が一瞬消えない)。山札に乗せた時の枠は赤。
- 札の裏は紺＋金の縁(卓の緑と見分けやすく)。予告「坊主 n枚・姫 n枚」は山札の中央の上。
- 注意: 札をめくる時に回転させる箱に透明度を付けると、立体が平らになって裏面が出る。消す時は表の札だけを薄くする。
