# 画面の見直し(元のアプリ 0.5.11 との比べ、2026-11-12)

基準: 元のアプリの画面のコード(`ui/Screens.kt`・`PlayScreen.kt`・`Common.kt`・`Theme.kt`)と、承認済みの見本(`docs/design-0.5.8/メニューと設定の見本.html`)。
元のアプリをビルドして画面を撮る方法は、この環境では Android SDK の取得と実行が安全確認で止められたため使えなかった。

## 元のアプリに合わせたもの
| 画面 | 合わせた点 |
|---|---|
| ホーム | 題名(あそび箱+収録数を金)、右上の「CPU 中級」、続きから(フェルトの板・再生の丸・2つ目からは小さく2列)、人数の切り替え(すべて/1人/2人/3人以上)、棚の見出しと線、タイル(盤の絵+名前+人数を下に)、下のタブ(ゲーム・みんなで遊ぶ・成績・設定) |
| タイルの絵 | 見本にある15種は見本の SVG をそのまま。残り15種は同じ素材の色で描き足した(`web/art.js`) |
| ゲームの設定 | 上の戻る・ルール、フェルトの板(絵・名前・ひとこと・人数と種類の札)、遊び方(CPUと対戦/手番ごとに交代)、人数と相手(合計の人数の − ＋、CPUの強さ、手番・ランダム)、手番ごとに交代の板(CPU と対戦の時は薄くして触れない)、ルール・ローカルルール(あり/なしはスイッチ、短い3つまでは行の右、ほかは行の下)、時間(1手の制限時間・時間切れの扱い)、下に固定のスタート |
| ルール | Catalog の説明の見出しと本文 |
| 対局 | 上の帯(戻る・箱の絵・名前・「CPU 中級」など、待った・ルール・最初から)、名札(駒の色の玉・名前・番/強さ/先後・数字、番は金の枠)、制限時間の行と降参、状態の一言(白い丸角)、盤は木の台、結果の板(勝利/敗北/引き分け・理由・点、もう一度/後攻でもう一度/ホーム) |
| 設定 | テーマ(ライト/ダーク/端末の設定)、置ける場所を表示、効果音、CPUの手番の長さ、CPUの強さ(初期選択)、名前、ライセンス |
| 成績 | CPUとの対戦(勝率・勝ち負け引き分け)、ひとりで(遊んだ回数)、成績を消す |
| 色 | Theme.kt の AsobiColors(ライト/ダーク)と同じ値 |

## まだ元のアプリと違うもの
- 盤の絵: チェスの駒は文字の記号、将棋の駒はおおむね同じ。元のアプリの細かい絵(駒の形・木目・ガラスの玉・カードの卓の顔の丸と吹き出し・花札の絵柄など)は再現していない。
- カードゲームの卓: 共通の簡単な卓。元のアプリのゲームごとの卓(大富豪の「出す」ボタン、7ならべの場の並べ方など)とは違う。
- 動く図つきのルール説明(RuleDemos)、役の一覧、駒の動きの説明(PieceGuide)、盤の動きの演出、紙吹雪、カウントダウンの大きな数字と赤い光、全員の帯(TurnOrderBar)、ダブルタップで CPU をとばす、プレイヤーの写真、確認用の場面。
- 通信の部屋の画面は、元のアプリの OnlineScreens.kt の見た目とは細部が違う(招待コードの交換・名簿・ゲームと設定の選択・チャット・待ったはある)。
- スピード・ソリティア・麻雀・道のりすごろくは画面がない。
