# ルール動画の注釈仕様（ユーザー指示 2026-11-23、全ゲーム共通・必読）

1. 矢印は安っぽい線画にしない。世間のチュートリアル動画のような、見栄えの良い矢印（塗り＋フチ＋影、カーブ可）を使う。
2. 説明文は画面下の帯ではなく「吹き出し」に入れる。
3. 矢印と吹き出しは、差す先が画面に表示されてから、ふわっとフェードインさせる。先が表示されていないのに矢印だけ先に出ているのは不自然で禁止。
4. 矢印・吹き出しは他の要素（席パネル・盤の情報・ボタン等）に被せない。空いている場所を通す・置く。
5. 提出前に必ずフレーム単位で確認する（対象の表示時刻、矢印の出る時刻、被りの有無）。
6. 吹き出しは最低4秒表示する（足りない場合は末尾の映像をフリーズして延ばす）。再生側は、動画が終わったら自動で次のステップへ進む。
7. 撮り直した動画を再送するときは新しいファイル名にする（端末側キャッシュで古い版が見え続けるため）。

# ルール画面の文章セクション仕様（ユーザー指示 2026-11-23）

- 並び順: ルール（動画）→ 補足 → ローカルルール → コツ。
- コツはルールの焼き直し禁止。基本的なコツ／有利に進めるためのコツ／上級なコツを、ジャンル分けは必須ではないが、質の高いものを十分に充実させる。

## 吹き出しの文字はみ出し防止（ユーザー指摘 2026-11-23、必須）
- 吹き出しの幅は「文字数×フォントサイズ」の概算で決めないこと。必ず実フォント（NotoSansCJK-Bold）の実測幅で、最長行＋左右20px以上の余白が入る幅にする。
- mk_overlay.py に自動拡張を組み込み済み（最長行の実測幅＋40px 未満の w は自動で広げ、WARN を出す）。WARN が出た場合は、吹き出しが他の要素（ボタン・共通UIの文字など）に被らないか必ず確認する。
- 提出前のフレーム検証では「文字が吹き出しのフチに触れていないか・はみ出していないか」を必ず目視確認する。

## スパイダー収録メモ（2026-11-24）
- 盤面は js/boards/extra.js の spider()（.sol.spider）。設定画面で 種類：スパイダー → マークの数：1種 を選んで開始（1種が標準）。
- 札は data-src="6+列" data-n="残り枚数" の要素。列のカードは上下に重なるため、n>=2 の札は要素中心ではなく上端+8px付近をクリックすること（中心を押すと上の札に当たる）。
- 初期配札はカスケードアニメーション（約5秒）。盤面の安定は「連続2回の読み取りが一致」で判定すること。DOM上は最初から54枚そろって見えるので、枚数だけの判定では不十分。
- 貪欲な自動プレイ（spiderChoose相当）では完成に届かず手詰まりになることがある。評価関数（連なりの長さ×10＋表向き枚数×2＋完成500）＋訪問済み状態の除外で1手先読みするドライバ（sp_rec3.cjs）で、13手目にK〜A完成を捕捉。
- 山札配布は別録画（sp_deal.cjs）。配布は全列に札があるときのみ可能で、録画開始時は配札後に4.5秒待ってから山札を押す。
- 動画とperfのオフセットは約+1.3秒。
