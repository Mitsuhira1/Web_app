6ニムト の遊び方

補足

駒と点数：し（10枚）=10点 / 香（4枚）=20点 / 馬（4枚）=20点 / 銀（4枚）=30点 / 金（4枚）=30点 / 角（2枚）=40点 / 飛（2枚）=40点 / 王（2枚）=50点。全32枚を4人で8枚ずつ分けます。

王の受けの制限：王は多くの攻めを受けられる万能の駒ですが、「し」と「香」の攻めだけは受けられません。し・香の攻めは、同じ駒でしか受けられません。

場が流れたら：全員がパスして攻めが一巡したら場が流れ、最後に攻めた人が好きな駒で攻め直します。新しい場の1枚目は、伏せて出すこともできます。

チーム戦：向かいに座る人（1・3番どうし、2・4番どうし）が味方です。点数はチームで合計します。

ローカルルール

勝利点150点（標準）
100点
王の倍付けあり（標準）：最後の2枚が連続で王（7枚目を受け、8枚目で攻める等）なら、上がりが倍の100点になります
なし

コツ

【基本】味方の攻めにはパス：相方が攻めた駒を自分が受けてしまうと、相方の上がりを邪魔することになります。味方の攻めには基本パス。逆に自分の攻めは、相方が受けやすい駒（相方が出しそうな駒）を選ぶと連携がつながります。

【有利】王は「上がり駒」の第一候補：王は50点と最も高く、受けにも使える万能駒です。序盤の受けで安易に切らず、終盤まで残しておくと「最後の攻め駒」として大きな得点になります。ただし、し・香の攻めは王で受けられない点は忘れずに。

【上級】王・王の倍付けを狙う：手駒が残り2枚になったとき、両方とも王なら倍付けで100点が入ります（標準設定）。王を2枚持っているときは、他の駒から先に出して、最後を王・王で締める組み立てを意識しましょう。
