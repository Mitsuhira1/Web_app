神経衰弱 の遊び方

ステップを選ぶと、実際の盤面の短い動画で説明します。

補足

  • 概要と目的：裏返して並べた札を2枚ずつめくり、同じ数字の2枚を当てて取るゲームです。札がなくなったら終わりで、取った組が一番多い人の勝ちです。
  • 人数と道具：52枚（同じ数字が4枚ずつ）または26枚（♠と♥の13枚ずつ）で遊べます。マークは関係なく、数字だけが同じならペアになります。
  • 当たりと外れ：2枚が同じ数字ならもらえて、続けてまためくれます。違う数字なら少し見せた後に裏に戻し、次の人の番になります。
  • 裏に戻るタイミング：外れた2枚は、番が移って次の人が1枚目をめくるのと同時に裏に戻ります。タイマーで戻るのではありません。
  • 取った札の表示：取った札は盤上から消えず、そのまま表向きで残ります。取った組の数は、右上の「取った組」で確認できます。
  • 1人で遊ぶとき：全部取るまでにめくった回数（2枚で1回）が結果になります。
  • CPUの強さ：CPUは強さによって覚えていられる枚数が違います。上級は全部覚えています。
  • 待った：「待った」はできません。

ローカルルール

  • 対戦形式：CPUと対戦／手番ごとに交代。設定画面に人数の選択肢はなく、どちらの形式も2人で遊びます。
  • CPUの強さ（CPUと対戦のときのみ）：初級／中級／上級（既定は中級）。
  • 手番（CPUと対戦のときのみ）：先手／後手／ランダム（既定は先手）。
  • 札の枚数：52枚／26枚（既定は52枚）。
  • 制限時間：なし／15秒／30秒／60秒（既定はなし）。
  • 時間切れのとき：ランダムな一手／負け（既定はランダムな一手）。

コツ

  • 基本：めくった札は、数字だけでなく場所もセットで覚えましょう。「あの場所が7」というように、場所のイメージで覚えると忘れにくいです。1枚目にめくる札は、まだ見たことのない場所を選ぶのが基本です。見たことのある場所を1枚目にめくっても、新しい情報は増えません。
  • 有利に進める：2枚目をめくるときは、1枚目と同じ数字の札をどこかで見ていれば、そこをめくります。見ていなければ、まだ見たことのない場所をめくって新しい情報を集めましょう。相手がめくった札もよく見ておくこと。相手の番で表になった札は、自分の番でも使える情報です。同じ数字が4枚あるうち3枚の場所が分かれば、残り1枚の場所が分かったも同然です。
  • 上級：覚えた札を「言葉」で整理すると、たくさん覚えられます。たとえば「Qは左上と右下」など、場所を言葉にして頭に置くのがコツです。相手がペアを取りそうな数字を覚えたら、その数字の残りの札を先に取ってしまうのも手です。序盤は情報を集めることを優先し、ペアが分かってきた終盤で一気に取るのが、取りこぼしの少ない進め方です。
