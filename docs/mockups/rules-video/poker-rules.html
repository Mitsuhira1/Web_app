ポーカー の遊び方

ステップを選ぶと、実際の盤面の短い動画で説明します。

補足

  • 1ゲームの流れ：全員が参加費10を出し、5枚ずつ配られます。①1回目の賭け → ②札の交換 → ③2回目の賭け（額は1回目の2倍）→ ④ショーダウンで勝敗を決めます。
  • 賭けの決まり：1回目の賭けは20ずつ、2回目は40ずつです。上乗せ（レイズ）は1回の賭けにつき3回までです。持ち点が足りない時は、持っている分だけで勝負に参加できます。
  • 交換：降りていない人は、要らない札を0〜5枚選んで山の札と1回だけ交換できます。
  • 役（弱い順）：ワンペア → ツーペア → スリーカード → ストレート → フラッシュ → フルハウス → フォーカード → ストレートフラッシュ（10・J・Q・K・Aの組み合わせはロイヤルストレートフラッシュ）。同じ役なら、役を作る数の大きい方（Aが一番強い）が勝ちです。
  • ショーダウン：残った人が手札を見せ、役の強い人が場のチップを全部もらいます。誰かが降りて残り1人になった手は、札を公開せずに勝ちです。
  • 勝敗：10ゲーム遊ぶか、1人を除いて全員の持ち点がなくなったら終わりです。持ち点の一番多い人の勝ちです。「待った」はできません。

ローカルルール

  • 対戦形式：CPUと対戦（標準）／手番ごとに交代（1台で順番に遊ぶ）も選べます。
  • CPUの強さ：初級（標準）／中級／上級。
  • 制限時間：なし（標準）／15秒／30秒／60秒。
  • 時間切れの扱い：ランダムな一手（標準）／負け。制限時間を「なし」にした時は選びません。
  • 人数・回数：4人・10ゲームで固定です。設定画面で変えることはできません。

コツ

  • 基本：交換の確率は頭に入れておきましょう。ペアから3枚替えるとツーペア以上になるのは約29%（スリーカード以上は約12%）、4枚のフラッシュから1枚替えてフラッシュになるのは約19%、両端の開いた4枚続きからストレートは約17%です。ペアができたら、まずはペアを残して3枚替えるのが基本形です。
  • 有利に進める：コールするかは「ポットオッズ」で考えましょう。場が100でコールに20なら、6回に1回以上勝てるならコールが得です。交換の枚数は相手の手の情報です。1枚だけ替える人はフラッシュかストレート狙いが多く、交換しない人は強い役を持っていることがあります。相手が何枚替えたかを見て、自分の役の強さを測り直しましょう。
  • 上級：弱い手で賭け続けないこと。序盤はワンペア（特にJ以上）からが目安で、降りるのも大切な一手です。ときどきのブラフも武器になります。交換しない、または強く賭けて、強い役があるように見せる手があります。ただしブラフは使いすぎると読まれるので、ここぞという場面に絞りましょう。
