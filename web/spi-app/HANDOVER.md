# 引き継ぎメモ：SPI試験対策 Web版の問題データ更新（v4.2・全1,073問）

## これは何か
Web版「SPI試験対策」の問題データを、監査済みの新問題バンク（version 4.2.0、全1,073問）へ差し替えた更新版です。アプリ本体（画面・動作）は前回公開版から変更ありません。変更ファイルは `spi_bank.json` と本メモのみです。

## 変更内容
- 問題を全983問 → **全1,073問**（非言語550／言語523）に置き換え。
- 541問は同一、382問は選択肢の並び替え（正解位置の偏り是正）、60問は選択肢の内容変更、90問は新規追加（推論30／表の読み取り15／長文読解12／文の並べ替え9／2空欄補充9／難関計算・確率15）。
- 問題データは第三者監査と再監査を通過した v4.2 と完全一致（N495の致命的欠陥・模試の時間超過は修正済み）。
- 全1,073問に詳細解説（`detailedExplanation`）を収録。
- 形式は従来どおり：1行目「正解は{ラベル}の「{選択肢文言}」です。」→→（語彙・長文系は）→（一部）。
- 重要な部分は **太字**、最も重要な部分は **__太字＋赤太下線__**、必要に応じて①②③と「下線部①」参照。
- 並び替え・内容変更があった問題は、解説中の選択肢ラベル・引っかけ解説も新しい選択肢に合わせて修正済み（機械検証で不整合0件）。新規90問は全問解き直して正解と一致を確認済み。
- `spi_bank.json` のトップレベルに `mockExams`（模試3本：65問／65問／55問、セクション別制限時間つき）を保持しています。現行Web版の本番モードは従来どおり「言語20＋非言語20問・70分・ランダム出題」で、`mockExams` はまだ使用していません（データのみ保持。模試モードの実装は今後の課題）。
- 削除するファイルはありません。

## 公開手順（Claude への依頼内容）
1. リポジトリ **Mitsuhira1/Web_app** の公開ブランチ **ccr-efc07031-6exjqs** を対象にします。
2. 既存の **`spi-app/`** フォルダ内の5ファイルを、ZIPの中身でそのまま差し替えてください（ファイルの追加・削除はしないでください）。
3. コミット・プッシュしてください（コミットメッセージ例：`SPI Web版の問題データをv4.2（1073問）に更新`）。
4. 公開確認：数分後に **https://mitsuhira1.github.io/Web_app/spi-app/** を開き、ホーム画面が表示されること、あわせて `spi_bank.json` が 200 で返ることを確認してください。
- ブラウザに古い問題データがキャッシュされている場合は、再読み込み（スーパーリロード）で新しいデータになります。

## 検証結果（差し替え実施側で確認済み）
- 問題データ：全1,073問でID重複なし、選択肢5つ・answerIndex・分類の不整合なし、模試の参照先は全て存在。
- 詳細解説：全問に収録、1行目の正解表記が全問正解と一致、記法（**／__）の開閉一致、全問に赤太下線あり、選択肢を引用した言及のラベル不整合0件。
- 動作：自動チェック36件全合格（従来分）。新規問題7問（推論・表の読み取り・難関損益・長文読解・文の並べ替え・空欄補充・並び替えで言及が多い語句の意味）をスマホ幅390px／PC幅1280pxで追加確認し、問題画面・解説画面とも横はみ出しなし、下線描画あり。

## 注意事項
- 進捗（正解・不正解・△マーク）は問題ID単位で localStorage に保存されるため、同一IDの問題の進捗はそのまま引き継がれます。
- サーバー側の設定は不要です。静的ファイルのみで動作します。動作確認は必ず http(s) 経由で行ってください。
- Android版（APK）への同じ問題データの適用は、この後の更新として別途行います（今回の対象はWeb版のみ）。
