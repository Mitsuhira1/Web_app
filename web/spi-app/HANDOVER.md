# 引き継ぎメモ：SPI試験対策 Web版の GitHub Pages 公開

## これは何か
Androidアプリ「SPI試験対策」（v1.1）の Web 移植版です。UI・収録問題（全983問＋詳細解説）・動作は Android 版と同一です。GitHub Pages で公開するために、以下の手順でコミット・プッシュをお願いします。

## 同梱ファイル（ZIPの中身）
| ファイル | 内容 |
|---|---|
| `index.html` | 画面の土台（エントリーポイント） |
| `style.css` | デザイン一式（ダーク／ライト両テーマ） |
| `app.js` | アプリ本体（画面遷移・練習・本番モード・戻る制御） |
| `spi_bank.json` | 問題データ（983問＋詳細解説、約1.5MB） |
| `HANDOVER.md` | このメモ |

## 公開手順（Claude への依頼内容）
1. リポジトリ **Mitsuhira1/Web_app** の公開ブランチ **ccr-efc07031-6exjqs** を対象にします。
2. 公開ルートの直下にファイルを置くのではなく、あそび箱（`pc-firebase/`）と同じ階層に、新しいフォルダ **`spi-app/`** を作り、ZIP の中身5ファイルをそのまま入れてください。公開URLは `https://mitsuhira1.github.io/Web_app/spi-app/` になります。
   - 既存ファイルの変更・削除は一切しないでください（追加のみ）。
   - ファイル名は変更しないでください（`spi_bank.json` は `index.html` と同じフォルダに必要です）。
3. コミット・プッシュしてください（コミットメッセージ例：`SPI試験対策 Web版を追加`）。
4. 公開確認：数分後に **https://mitsuhira1.github.io/Web_app/spi-app/** を開き、スプラッシュ後にホーム画面（SPI試験対策／ひたすら解く）が表示されることを確認してください。あわせて `https://mitsuhira1.github.io/Web_app/spi-app/spi_bank.json` が 200 で返ることも確認してください。

## 動作仕様（公開後の確認ポイント）
- 進捗（正解・不正解・△マーク）とテーマ設定はブラウザの localStorage に保存されます。端末・ブラウザごとに独立です。
- ブラウザ／スマホ本体の「戻る」は、アプリ内の戻るボタンと同じ動作をします（1つ前の画面に戻る）。ページがいきなり閉じることはありません。
- メニュー（ホーム）画面で「戻る」を押すと「終了しますか？」の確認ダイアログが出ます。「終了する」を選ぶと、来たページに戻ります（直接開いた場合は終了画面を表示します）。
- 本番モード実施中に「戻る」を押すと「試験を中断しますか？」の確認が出ます。
- 本番モードは言語20問→非言語20問の順（各分野内はランダム）、制限時間70分、結果にランク（S〜E）を表示します。
- 下部ボタンはスマホのセーフエリア分の余白を確保済みで、ブラウザのUIと被りません。

## 注意事項
- サーバー側の設定（.htaccess 等）は不要です。静的ファイルのみで動作します。
- `file://` で直接開くと問題データ（JSON）を読み込めないため、動作確認は必ず http(s) 経由で行ってください。
- Android 版（APK）のプロジェクトは別に存在します。今回の対象は Web 版のみです。
